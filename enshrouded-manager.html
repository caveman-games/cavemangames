Enshrouded Server Manager

A lightweight, user-friendly Windows desktop utility built with Flutter to configure and run your Enshrouded dedicated server without touching raw JSON files.

Key Features

  • Interactive UI Sliders: Easily tweak Enemy damage/health, Player stats, Survival mechanics, and Resource multipliers with exact percentage steps.
  • User Groups & Passwords: Secure your server by configuring custom roles (Admin, Friend, Guest, Visitor) and permissions.
  • Auto-Path Detection: Automatically scans standard Steam directories for your server executable.
  • Live Console Log: Start and stop your server process directly from the app while monitoring console output live.
